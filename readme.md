# Proyectos de Python

Una colección de scripts/códigos útiles en Python para automatización, descargas y hacking.

## Contenido del Proyecto

Este repositorio contiene 5 proyectos independientes:

### 1. **Descargador de Videos de YouTube**

   - Descarga videos directamente desde YouTube
   - Ubicación: `Script-Python-Download-main/`
   - **Dependencias**: librería de descarga de YouTube

### 2. **Capturador de Pantalla**

   - Toma capturas de pantalla y las guarda automáticamente
   - Ubicación: `Script-Python-Screenshot-main/`
   - **Características**: Guarda las imágenes en la carpeta de imágenes del proyecto

### 3. **Registrador de Teclas (KeyLogger)**

   - Captura teclas presionadas del teclado
   - Ubicación: `Script-Python-KeyLogger-main/`
   - **Características**: Monitoreo y visualización de teclas en lista

### 4. **Escritura Automática**

   - Automatiza la escritura de texto en cualquier parte de la pantalla
   - Ubicación: `Script-Python-AutomaticWriting-main/`
   - **Dependencias**: `pyautogui`
   - **Características**: Posicionamiento inteligente de cursor y escritura automática

### 5. **Gestor de Atajos Personalizados**

   - Crea y configura atajos de teclado personalizados
   - Ubicación: `Script-Python-Top_Shortcut-main/`
   - **Características**: Abre aplicaciones, sitios web, ejecuta scripts con palabras clave

## Instalación Rápida

Cada proyecto tiene sus propias dependencias. Consulta el README dentro de cada carpeta para instrucciones específicas.

```bash
# Ejemplo para AutomaticWriting
pip install pyautogui
```
