# Contribuciones

¡Gracias por tu interés en contribuir a este proyecto!

## Cómo Contribuir

1. **Reporta Errores**: Si encuentras un bug, abre un issue describiendo:
   - Qué hiciste
   - Qué sucedió
   - Qué esperabas que sucediera

2. **Sugerencias de Mejora**: Comparte tus ideas para mejorar los scripts

3. **Documenta**: Ayuda mejorando la documentación o añadiendo ejemplos

4. **Código**: Si quieres contribuir con código:
   - Fork del repositorio
   - Crea una rama para tu feature
   - Commit de tus cambios
   - Push y abre un Pull Request

## Directrices de Código

- Usa nombres de variables descriptivos en español o inglés
- Añade comentarios explicativos
- Prueba tu código antes de subir
- Mantén el código limpio y legible

## Reporte de Bugs

Por favor incluye:

- Sistema operativo
- Versión de Python
- Pasos para reproducir el error
- Mensajes de error
